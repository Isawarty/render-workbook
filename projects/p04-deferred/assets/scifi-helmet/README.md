# Sci-Fi Helmet asset

Source: [Khronos glTF Sample Assets — SciFiHelmet](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/SciFiHelmet)

- Original model: Michael Pavlovic
- glTF conversion: Norbert Nopper
- Asset license: CC0-1.0
- Local change: the four PNG textures were resized from 2048×2048 to 1024×1024
  for a smaller course checkout. Geometry and glTF material bindings are unchanged.

The asset exercises core glTF 2.0 metallic-roughness PBR with `POSITION`, `NORMAL`,
`TANGENT`, `TEXCOORD_0`, base-color, metallic-roughness, normal and ambient-occlusion
textures. See the upstream [license file](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/SciFiHelmet/LICENSE.md)
and [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).
